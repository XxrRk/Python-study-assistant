# 输出语言与术语（v0.7.0）

本规则定义卡片输出语言、字段标签、代码/技术术语和双语模式。语言选择不改变 Deck 字段名、ID 或导出列名。

## 语言选择

1. 用户明确指定语言时使用指定语言（如中文、英文）。
2. 用户未指定时，跟随材料的主要语言。
3. 材料混合语言时，以用户目标语言为准；没有目标语言时以正文主要语言为准。
4. 不要在同一张卡片里混用中英文标签。

## Markdown 标签

| 中文 | 英文 |
| --- | --- |
| 知识点 | Knowledge point |
| 例子 | Example |
| 自测问题 | Self-check question |
| 来源 | Source |

标题仍使用 `### 序号. 标题`；字段顺序不变。

## 不翻译的内容

- 代码、命令、变量名、函数名、类名；
- 包名、导入名、安装命令；
- 文件路径、扩展名；
- API、异常名、标准库模块名；
- 输出中的具体数值、版本号和错误信息。

可以翻译这些内容的**解释**，但不要改写代码标识符。

## 双语模式

- 先完整输出一种语言，再按同一卡片结构输出另一种语言；
- 两种语言使用相同的卡片数量和顺序，Deck 模式下复用同一组 `card_id`；
- 不把两种语言塞进同一字段造成阅读困难；
- 用户只要求“术语双语”时，可在括号中保留英文术语，不必整卡双语。

## 术语表

- 用户提供的术语表优先于默认译法；
- 同一术语在全篇保持一致；
- 没有通用译法的库名/API 保留英文；
- 文件/项目已有术语表时先读取再输出。

## Deck 与导出

- Deck 字段名、`schema_version`、`card_id`、`source_id`、`source_ref` 不随语言改变；
- JSONL/CSV 表头不翻译；
- Anki TSV 的 Front/Back 内容使用目标语言，Tags 保持稳定 ASCII；
- 双语 Deck 不创建重复卡片；如用户要求两种语言各一份 Deck，必须明确说明会复制卡片并分配新 ID。

## 自检

- 标签语言一致；
- 代码/包名/API 未被翻译；
- 双语输出卡片数量和 ID 不变；
- 术语表译名一致；
- 导出列名未翻译。
